### Observations (not counted as defects)

In a pack-racer that's a standing head start; reads as a deliberate difficulty aid, but it means the player rarely experiences mid-pack launches.
- **Draft cone is still 2D** (`_draftRel…setY(0)`, `Kart.ts:909`) — an airborne follower is geometrically eligible to charge a draft. Still theoretical: the follower also needs `forwardSpeed > draftMinSpeed` and matching heading, and any burst obeys the normal cooldown — harmless if it ever fires mid-hop.

Design intent per tuning comments, flagged for awareness.
- **`posDown` outnumbers `posUp` ~2.5:1 this session** (110 vs 44) — honest transitions while the crude autopilot traded places through wall-scrapes, not a stinger loop. The GO-seeded `lastPos` correctly prevents phantom start-move stingers.

## Fix direction for D1

`RaceHud.ts:609-621` — label ticker rows by their index in the sorted `order` array (`P${i+1}`) when `race.phase === 'countdown'` (or always — the sort already encodes the true order), instead of stamping shared-rank `positionOf(r)` on each row. Keeps the tie-share semantics for finished results where it's documented, and stops the every-race 4-way "P1" board.
